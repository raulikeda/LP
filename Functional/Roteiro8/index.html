    Roteiro 8 (Functional) - v3.0

    Entrega: 23/Apr/2026 às 07h15

    Objetivos

    1. Geração de Código

    Exemplo de Código:

    let mut i:i32;
let mut n:i32;
let mut f:i32 = 1;
n = scanln!();
i = 2;
while (i < n + 1) {
  f = f * i;
  i = i + 1;
}
println!(f);

    Mesmo exemplo em Assembly NASM (gerado pelo compilador):

    section .data
  format_out: db "%d", 10, 0 ; format do printf
  format_in: db "%d", 0 ; format do scanf
  scan_int: dd 0; 32-bits integer

section .text

  extern printf ; usar _printf para Windows
  extern scanf ; usar _scanf para Windows
  ; extern _ExitProcess@4 ; usar para Windows
  global _start ; início do programa

_start:
  push ebp ; guarda o EBP
  mov ebp, esp ; zera a pilha

  ; aqui começa o codigo gerado:

  sub esp, 4 ; var i int [EBP-4]
  sub esp, 4 ; var n int [EBP-8]
  sub esp, 4 ; var f int [EBP-12]

  mov eax, 1
  mov [ebp-12], eax ; f = 1

  push scan_int ; endereço de memória de suporte
  push format_in ; formato de entrada (int)
  call scanf
  add esp, 8 ; Remove os argumentos da pilha

  mov eax, dword [scan_int] ; retorna o valor lido em EAX

  mov [ebp-8], eax ; n = Scan()

  mov eax, 2
  mov [ebp-4], eax ; i = 2

  loop_34: ; label do loop 

  mov eax, 1
  push eax ; empilha 1

  mov eax, [ebp-8] ; recupera n

  pop ecx
  add eax, ecx ; n + 1
  push eax ; empilha n + 1

  ; condicional do loop
  mov eax, [ebp-4]; recupera i

  pop ecx
  cmp eax, ecx
  mov eax, 0
  mov ecx, 1
  cmovl eax, ecx ; i < n + 1

  cmp eax, 0 ; se a condição for falsa, sai
  je exit_34

  ; bloco de comandos
  mov eax, [ebp-4] ; i
  push eax ; empilha i
  mov eax, [ebp-12] ; f
  pop ecx ; desempilha i
  imul ecx ; f * i
  mov [ebp-12], eax ; f = f * i

  ; incremento
  mov eax, 1
  push eax ; empilha 1
  mov eax, [ebp-4]
  pop ecx
  add eax, ecx ; i + 1

  mov [ebp-4], eax ; i = i + 1

  jmp loop_34
  exit_34:

  mov eax, [ebp-12]
  push eax ; empilha f
  push format_out ; formato int de saida
  call printf ; Print f
  add esp, 8 ; limpa os argumentos

  ; aqui termina o código gerado

  mov esp, ebp ; reestabelece a pilha
  pop ebp

  ; chamada da interrupcao de saida (Linux)
  mov eax, 1   
  xor ebx, ebx 
  int 0x80     
  ; Para Windows:
  ; push dword 0        
  ; call _ExitProcess@4

    Técnicas

    Nesse roteiro não haverá alterações no Lexer nem no Parser. Você também não irá alterar os métodos evaluate dos nós. Contudo, será criado um método chamado generate com o type Node. Consequentemente, todos os nós que herdam essa classe, terão que implementar o código do método. generate retornará uma String

    Antes de explorar cada nó, alguns ajustes são necessários.

    Classe SymbolTable e Variable

    Para guardar a posição de uma variável na pilha, será necessário armazenar o deslocamento relativo ao registrador EBP para cada variável. Isso será feito com um novo campo no type Variable chamado offset.

    Além do construtor dessa classe, os métodos da SymbolTable que interagem com objetos do tipo Variable também precisam ser adaptados.

    A ideia é que cada nova variável, um deslocamento de 4 bytes será considerado. Logo, a primeira variável declarada terá um deslocamento de 4 bytes (ou seja, [EBP-4] porque a pilha cresce para baixo). A segunda variável terá um deslocamento de 8 bytes, e assim sucessivamente. Será considerado sempre variáveis inteiras de 32 bits e portanto o deslocamento será fixo de 4 bytes.

    Concatenando o Assembly

    Ao rodar generate, a main receberá todo o assembly gerado pelos nós. Esse assembly precisa ser concatenado com um cabeçalho e um rodapé com instruçÕes adicionais. A sugestão é colocá-los em arquivos adicionais. Ao final, carregar o conteúdo, concatenar e salvar um arquivo de saída.

    Atenção

    Note no código acima que as instruções mudam conforme o Sistema Operacional. Antes de enviar para o servidor, é preciso deixar a saída pronta para o Linux.

    Type Node

    Para as instruções if e while serão precisos utilizar labels no código de saída. Como pode haver diversas instruções, inclusive encadeadas, não será possível utilizar marcações fixas, como por exemplo:

    label: ; label do while 1

; alguma instrução

label: ; label do while 2

jmp label ; qual label?

    Portanto cada nó terá um identificador numérico único que ao escrever o rótulo, irá adicionar o identificador, gerando rótulos únicos, por exemplo:

    ; instruções do primeiro filho: inicialização
loop_34: ; o unique identifier do nó while é 34

; instruções do primeiro filho - retorna o resultado true/false em EAX

cmp eax, 0 ; verifica se o teste deu falso
je exit_34 ; e sai caso for igual a falso.

; instruções do segundo filho: bloco de instruções

jmp loop_34 ; volta para testar de novo
exit_34:

    Gere identificadores únicos para utilizar em cada if e while no código

    Função generate

    Cada nó terá uma implementação própria do generate. Ler o PDF da aula para mais detalhes.

    Lembrem-se que o retorno de um nó sempre acontecerá em EAX e você usará sempre o ECX como suporte. Não usar o EBX.

    Não será gerado código para os nós que representam ou operam strings.

    Tarefas

    • Criar arquivos com o cabeçalho e o rodapé. Concatenar o conteúdo quando for salvar o arquivo de saída.
    • Criar uma função newId que cria um id único. Ele será IO Int, mas pode utilizar unsafePerformIO para extrair o número.
    • Alterar o tipo Variable criando o campo shift para armazenar o deslocamento da pilha. Alterar os métodos da SymbolTable para considerar o novo atributo.
    • Implementar o generate para gerar código para as seguintes operações:
    • Declaração de variáveis
    • Operações unárias e binárias
    • Atribuição
    • Condicional
    • Loop
    • Print
    • Scan
    • Você pode aproveitar as subrotinas do código de apoio do exemplo acima (condicionais) publicadas no Blackboard
    • O seu compilador deve escrever um arquivo asm com o mesmo prefixo de entrada. Exemplo: teste.rs sai teste.asm
    • Para montar o código e transformá-lo em executável x86 + Linux (versão do Servidor):
    $ nasm -f elf32 -o program.o program.asm
$ gcc -m32 -no-pie -nostartfiles -o program program.o -e _start
    • Para montar x86 + Windows (verificar as constantes do código):
    $ nasm -f win32 -o program.obj program.asm
$ gcc -m32 -no-pie -nostartfiles -o program.exe program.obj -e _start

    Para mais informações: https://en.wikipedia.org/wiki/Executable_and_Linkable_Format

    Em caso de problemas com o assembly, use o gdb.

    Extra Credit - pontos: +0,6

    Question

    Implementar a geração de código Assembly de funções (v2.3). Assim como esse roteiro, desconsiderar strings. Essa tarefa fica mais simples após finalizar a versão v2.3.

    Uma função é basicamente um procedimento (bloco de coódigo) em Assembly. Ao iniciar a função, deve-se zerar o EBP e o ESP. Antes de retornar, deve-se reestabelecer esses registradores.

    Os argumentos da função serão passados na pilha. Para acessar os argumentos, usa-se o endereço [EBP+N] (lembre-se que o EBP foi zerado). Atenção: [EBP+4] é o endereço de retorno da função e muito cuidado com a ordem de empilhamento e leitura dos argumentos (é uma pilha).
