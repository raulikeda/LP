    Roteiro 9 (Functional) - v2.3

    Entrega: 07/May/2026 às 07h15

    Objetivos

    1. Implementar Declarações de Funções
    2. Escopo de variáveis

    Exemplo de sintaxe:

    let mut b:i32 = 5; // Variável Global

fn soma(x:i32, y:i32) ->  i32 {
  let mut a:i32; // Variável Local
  a = x + y; 
  println!(a); // Imprime 7
  return a;
}

fn main() ->  () {
  let mut a:i32;
  {
    let mut b:i32;
    a = 3;
    b = soma(a, 4);
    println!(b); // Imprime 7
  }
  println!(a); // Imprime 3
  println!(b); // Imprime 5
}

    Funções

    Como exemplificado acima, a linguagem permite declarar funções simples e com declaração de tipo. Todas as funções a princípio possuem visibilidade pública e podem ser usadas em outras Funções. Não será possível declarar uma função dentro de uma função.

    • Na linguagem se a função não declarar um tipo, o tipo será automaticamente unit. A função main é obrigatória.

    Lexer

    • Adicionar a palavra reservada fn: token FUNC
    • Adicionar a palavra reservada return: token RETURN
    • Adicionar o símbolo ,: token COMMA
    • Adicionar o símbolo ->: token ARROW

    AST - Parte I

    • Adicionar o Node FuncDec name returnType [(arg, argType)] Block
    • Adicionar o Node FuncCall name [Expression]
    • Adicionar o Node Return Expression

    Parser

    • Adicionar o parse_func_declaration. Vai gerar um nó FuncDec
    • FuncDec terá 4 argumentos. O primeiro será um Identifier e o último será um Block. O tipo de retorno da função será o segundo argumento. O terceiro depende da quantidade de argumentos da função.
    • Adicionar a chamada do parse_func_declaration no parse_program. Precisa pensar um pouco como decidir o caminho correto.
    • No parse_statement:
    • Adicionar a chamada de função após um token IDEN. Se houver um OPEN_PAR é chamada de função. Se houver um ASSIGN é uma atribuição. Vai gerar um nó FuncCall
    • FuncCall terá 2 argumentos. Além do nome da função, haverá os valores dos argumentos na chamada. São expressões.
    • Adicionar o tratamento do RETURN. Vai gerar um nó Return
      • Return terá apenas 1 argumento. Será uma expressão.
    • No parse_factor:
    • Adicionar a chama de função (igual ao anterior)

    FuncTable

    • Criar um tipo FuncTable que armazerá as funções declaradas.
    • Funcionará de forma análoga à SymbolTable atual. Não permitirá modificar funções.
    • Alterar todas as funções execute para receber uma FuncTable como argumento.

    SymbolTable

    • Modificar o construtor do tipo para uma lista ligada:
    type Frame = [(String, Variable)]
data SymbolTable
  = EmptyST
  | Scope Frame SymbolTable
  deriving (Show, Eq)

    Com isso é possível criar uma tabela vazia (EmptyST) ou um novo escopo (Scope) com novo frame.

    • Modificar as as funções createVar, setVar, getVar para se adequar ao novo modelo de dados.
    • Precisa implementar a lógica recursiva na busca e modificação.
    • Criar 2 métodos para adicionar e remover escopos: pushScope :: SymbolTable -> SymbolTable e popScope :: SymbolTable -> SymbolTable.
    • Verificar os erros na utilização da nova SymbolTable nas funções evaluate e execute.

    Node Return

    O nó Return é um statement, logo ele será tratado na função execute. Ele deve retornar o valor do evaluate do nó filho dele, porém execute não retorna valor.

    • Modificar o tipo de retorno da função execute para IO ExecResult, onde:
    data ExecResult
  = Normal SymbolTable FuncTable
  | Returned Variable SymbolTable FuncTable
    • Com isso. Os nós que retornam valor, usarão o padrão Returned, já os nós atuais utilizam o padrão Normal.

    Node Block

    • Trocar a execução via foldl para uma recursão.
    • Precisa retornar o valor no Block quando o filho executado for um Return
    • Precisa interromper a execução do bloco quando houver um retorno (padrão Returned)

    Ainda, com a possibilidade de haver Block dentro de outro Block, precisa tratar o escopo adequadamente:

    • Precisa criar um novo escopo na SymbolTable quando o filho a ser executado for um outro Block. Utilizar o novo escopo no evaluate do filho (Block)
    • Será necessário também ajustes nos nós If e While para retornar valores se o Block retornar valor.

    Node FuncDec

    FuncDec é um nó muito simples. O execute apenas o adiciona na FuncTable.

    Node FuncCall

    Aqui é onde a execução realmente acontece. Como uma função pode ser chamada diversas vezes com parâmetros diferentes, precisa recuperar a assinatura da função e montar a chamada. Segue a lista de tarefas:

    • Verifique se a função foi declarada na FuncTable
    • Recupere a estrutura da função
    • Verifique se o número de argumentos na chamada bate com a declaração
    • Crie um novo escopo na SymbolTable
    • Simultaneamente:
    • Declare os argumentos no novo escopo
    • Realize o evaluate dos argumentos passados e preencha no escopo
    • Capture o return, se houver, e verifique o tipo de retorno da função. Retorne o valor (cuidado com o void/unit)

    Tarefas

    1. Atualize a EBNF e o DS no GitHub. Essa é a versão final!
    2. Adicionar os novos tokens no Lexer
    3. Adicionar os novos nós vazios: FuncDec, FuncCall e Return
    4. Modificar o Parser:
    5. Adicionar parseFuncDeclaration - irá gerar um nó FuncDec
    6. Adicionar a declaração de funções e variáveis globais no parseProgram
    7. Modificar os métodos para a chamada de função - irá gerar um nó FuncCall
    8. Adicionar Return ao Statement - irá gerar um nó Return
    9. Alterar a SymbolTable:
    10. Modificar para uma estrutura de lista ligada reversa
    11. Alterar o getter/setter para buscar recursivamente
    12. Implementar/Alterar os Nodes:
    13. Nó Return:
      • Retornar o valor/tipo do execute do único filho
    14. Nó Block:
      • Alterar o while para retornar quando o filho filho executado for um Return
      • Criar um novo escopo SymbolTable encadeado quando o nó filho a ser executado for um Block
    15. Nó FuncDec:
      • Criar uma nova variável na SymbolTable, passando o próprio nó como valor. Precisa colocar o tipo e uma sinalização que é uma função
    16. Nó VarDec:
      • Modificar sinalizar que uma variável a ser criada não é uma função
    17. Nó FuncCall:
      • Recuperar o nó da declaração da função na SymbolTable
      • Verificar se o número de argumentos está correto
      • Criar um novo escopo SymbolTable encadeado
      • Declarar os argumentos na nova SymbolTable e atribuir os valores da chamada, em ordem
      • Se houver return no Block, retornar o valor
    18. Nós If e While:
      • Se o filho do tipo Block retornar valor, esses nós devem retornar esse valor
    19. No run, antes de retornar, adicionar um FuncCall node na raiz para chamada da main()

    Atenção

    Tomar cuidado com as possíveis mensagens de erro.

    Base de Testes:

    Além do código exemplo acima que deve funcionar conforme o esperado, teste os seguintes elementos:

    • Com erros:
    • Chamar a função com número incorreto de argumentos.
    • Passar argumentos de tipos diferentes.
    • Chamar uma função que não existe.
    • Usar uma variável fora de escopo.
    • Sem erros:
    • Fazer uma função recursiva.
    • Sugira testes adicionais

    Question

    Implementar struct adaptada no compilador. Assim como funções, struct é apenas um molde e só é um objeto concreto após uma instância. Cuidado com a tipagem dos atributos. É possível aninhar diversas structs. Não implementar a inicialização na declaração.

    Segue um exemplo abaixo: 

      struct A {
    let mut b:i32;
  };

  fn main() ->  (){
    let x:A; // Creates an instance of A
    x.b = 1; // Assigns 1 to x.b
    println!(x.b); // Prints 1
  }
