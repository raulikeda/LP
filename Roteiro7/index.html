    Roteiro 7 - v2.2

    Entrega: 13/Oct/2026 às 07h15

    Objetivos

    1. Aprimorar a estrutura de programa
    2. Implementar Tipos nas Variáveis
    3. Implementar Strings

    Requisitos do Roteiro

    Para implementar as modificações propostas nos roteiros será preciso modificar alguns pontos-chave, principalmente na etapa semântica.

    Lexer

    Adicionar os novos tokens:

    • true, false - token BOOL
    • Valores string: separar todo o conteúdo entre aspas. Declarar um token tipo STR
    • ,, ` - tokenTYPE`

    SymbolTable

    Será preciso adicionar um novo atributo na classe Variable, chamado type. Alterar o construtor para preencher esse atributo na inicialização.

    Em seguida será necessário criar um novo método na SymbolTable chamado create_variable(). Esse método substituirá a setter na função de declarar a variável.

    Como consequência, é preciso fazer um ajuste no setter para verificar se a variável foi declarada previamente.

    AST - Parte 1

    Adicionar os novos nós:

    • BoolVal: sem filhos. Atua de forma análoga ao IntVal
    • StringVal: sem filhos. Atua de forma análoga ao IntVal
    • VarDec: possui 1 ou 2 filhos. O primeiro é do tipo Identifier e o segundo é alguma expressão. O seu evaluate irá declarar a variável na SymbolTable recebida como argumento. Se o segundo filho estiver presente, irá atribuir o valor da expressão à variável. O tipo da variável estará no atributo value do nó.

    Parser

    Adicionar a declaração de variáveis no diagrama Statement. O método deverá retornar um nó do tipo VarDec, com o tipo consumido no atributo value desse nó. O primeiro filho será o identifier consumido e, se houver atribuição, a expressão analisada será o segundo filho do nó.

    Também adicionar o consumo de string e boolean no factor, criando os nós StrVal e BoolVal, respectivamente.

    AST - Parte 2

    Todos os nós que retornam valores, passarão a retornar um objeto do tipo Variable, contendo um valor e um tipo correspondente. É preciso ajustar todos os returns para retornar corretamente.

    Todos os nós que operam valores (ex BinOp), precisarão se adaptar aos novos retornos dos filhos.

    Adicionalmente, adicionar a verificação de tipos para as operações. Ver os slides da aula para mais detalhes. Muito cuidado com a concatenação.

    Tarefas

    1. Atualize a EBNF e o DS no GitHub
    2. Altere as classes e métodos descritos no roteiro (sugestão: seguir a ordem do roteiro)

    Base de Testes:

    Proponha um programa de testes, com os seguintes elementos:

    • usar de variáveis de todos os tipos.
    • verificar se programas antigos ainda funcionam.
    • operar tipos incorretos.
    • testar um if/while com uma string de entrada.

    Extra Credit

    Question

    Implementar a operação de casting. Ele é um operador unário que possui a maior prioridade, apenas atrás do parênteses. O tipo a ser convertido será sinalizado na estrutura do operador. Implementar também números do tipo float. Será possível realizar operações entre int e float livremente, mas o resultado será sempre float quando incluir um número float na operação.

    Segue um exemplo abaixo:

    c float y = 1.6; int x = (int) y; // Converts to INT 2 and assign to x y = x + y; // z receives FLOAT 3.6
